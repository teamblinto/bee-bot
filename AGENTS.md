# Bee Bot

Electron desktop app wrapping a React web app, in a pnpm workspace on Vite+ (`vp`).

Fight scope creep. Do not introduce machinery because it looks impressive; understand the real constraint, then build the smallest thing that makes the correct behavior unsurprising.

## Where code lives

- `apps/web` - React/Vite UI, TanStack Router, Tailwind.
- `apps/desktop` - Electron shell that loads the web app and supervises the server.
- `apps/server` - headless `beebotd`: SQLite, HTTP, WebSocket. Never imports `electron`.
- `packages/contracts` - Zod schemas and `protocolVersion`, shared by all three apps.
- `scripts/dev-runner.ts` - sets up the environment for `pnpm dev:desktop`.

## Commands

`vp` is a dev dependency: use `pnpm exec vp` or a package script.

- `pnpm dev:desktop` - web dev server (port 5833) plus Electron.
- `pnpm build`, then `pnpm start:desktop` - run the production build.
- `pnpm fmt`, `pnpm lint`, `pnpm typecheck`, `pnpm test`.
- `pnpm dist:desktop:win` - build the installer into `apps/desktop/release`.

## Verifying

- Before you finish, run format, lint, typecheck and test.
- Test behavior that can break. Leave out tests for what types already guarantee, trivial logic and copy text.
- Flaky tests are fixed, not retried.
- User-visible changes get one pass in the real app, not just tests.

## Conventions

- `apps/web/src/routeTree.gen.ts` is generated by the router plugin and committed. Do not edit it by hand.
- Inferred types over annotations. `any` is the enemy.
- Default to no comment. Write one only for a constraint, an external quirk, or an invariant the code can't show.
- React effects are for synchronizing with something outside React. Derive in render and act in handlers.
- Kill only processes you started, by the PID you tracked. Never kill by name or pattern.
- Do not commit implementation plans, research notes or agent scratch files.
- Never make a PR unless the developer explicitly asks. Conventional commit titles, plain language: `fix(web): new threads no longer spike CPU`.
